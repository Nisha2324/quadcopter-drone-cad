# Quadcopter Drone CAD Design

A component-level 3D CAD modeling project of a quadcopter drone, developed using SOLIDWORKS. The repository contains the individual part models and assembled CAD design for mechanical and electrical component integration.

## Project Overview

This project focuses on designing and assembling a quadcopter drone in a 3D CAD environment. Individual components were modeled and brought together into a complete assembly to visualize the overall structure and component arrangement.

## Objectives

- Develop individual 3D CAD models for drone components.
- Assemble the modeled components into a complete quadcopter design.
- Understand mechanical component placement and assembly relationships.
- Organize native CAD files for documentation, review, and future development.

## Tools and Technologies

- **CAD Software:** SOLIDWORKS
- **File Formats:** SOLIDWORKS Part (`.SLDPRT`) and Assembly (`.SLDASM`)
- **Project Type:** Mechanical CAD design and assembly modeling

## Components Modeled

The repository includes CAD models for the following components, as applicable to the assembly:

- Drone frame and structural arms
- Motors and propellers
- Battery and electrical units
- Electrical connectors and distribution board
- Spacers, nuts, and other fastening components
- Complete drone assembly

## Design Workflow

1. Model individual mechanical and electrical components in SOLIDWORKS.
2. Bring the modeled components into assembly documents.
3. Position and assemble the components to represent the overall drone configuration.
4. Review the assembled CAD model and organize the native project files.
5. Document the design for portfolio presentation and future iteration.
